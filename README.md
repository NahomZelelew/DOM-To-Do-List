# DOM To-Do List

A simple To-Do List project built with HTML, CSS, and JavaScript to practice DOM manipulation and events.

## Features

- Add new tasks
- Delete tasks
- Mark tasks as completed
- Press Enter to add a task
- Automatically renumber tasks after deletion

## Technologies Used

- HTML
- CSS
- JavaScript
- DOM Manipulation

## Purpose

This project was created as part of my JavaScript learning journey to practice working with the DOM, events, and dynamic elements.
